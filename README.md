# 📌 Sobre o Projeto

O **Guia de Fundamentos do Sistema Financeiro Nacional e Investimentos** foi desenvolvido como a **base de conhecimento** do projeto **BIA Academy Finance**, uma assistente virtual para educação financeira construída com Inteligência Artificial Generativa.

Durante o desenvolvimento da BIA Academy Finance, tornou-se necessário estruturar um conjunto organizado de conteúdos contendo conceitos fundamentais do Sistema Financeiro Nacional (SFN), investimentos, produtos financeiros e terminologias utilizadas no mercado.

Este repositório reúne esse conhecimento em formato estruturado, composto por:

- 📖 Resumos organizados
- 📚 Glossário de conceitos
- 🤖 Prompts reutilizáveis para estudos com IA
- 📑 Referências bibliográficas

Além de servir como material de apoio ao aprendizado, este projeto demonstra uma etapa importante do desenvolvimento de aplicações baseadas em Inteligência Artificial: **a construção da base de conhecimento que alimenta o sistema**.

O projeto foi desenvolvido durante o **Bootcamp Bradesco - GenAI & Dados – IA Generativa e Dados**, promovido pela **Digital Innovation One (DIO)**.

---

# 🌟 Por que este projeto é relevante?

Aplicações de Inteligência Artificial dependem de uma base de conhecimento organizada e confiável.

Antes do desenvolvimento da **BIA Academy Finance**, foi necessário estruturar conteúdos sobre educação financeira para garantir respostas mais consistentes e contextualizadas.

Este projeto representa exatamente essa etapa.

Além disso, demonstra competências em:

- Organização do conhecimento
- Documentação técnica
- Educação financeira
- Engenharia de Prompts
- Estruturação de bases para aplicações de IA
